## 2. 训练前必须冻结的资格条件

这些是训练/评测实施者须在结果可见前填写的记录项，不是声称本轮已实现的新模型。当前 `convex_samehead_mm` 和 `free_complex_mm` 尚无可核对的新配置；不得事后凭模型名宣称条件已满足。

1. **同头定义。** 固定骨干、最后卷积核/stride、BN有无、bias、激活、初始化尺度、精度及优化参数。5个波束的凸logits与复仿射自由参数不是天然同维张量：必须写明最后一层到5个logits的固定映射、各通道是否有效、参数总量和梯度路径，禁止看结果后换映射或截取通道。若只能匹配BN/初始化等结构而未匹配有效输出维数，应称“头结构匹配”，不能称“逐参数完全相同”。
2. **初始功能也要检查。** 记录初始化的有效系数、有效滤波器与输出；零bias的softmax通常从均匀融合开始，仿射零自由参数从锚点开始，仅同一尺度/随机种子不能消除这种差别。若初始功能、有效参数量或梯度参数化仍不同，结论须保留这些混杂，不将C1解释为唯一因素的因果证明。
3. **共同训练协议。** 主对照使用x_dp的同一STFT MSE、相同数据/字典/STFT、含失配训练与含失配验证、相同seed_key和数据顺序。以已有 `configs/model_affine.yaml`、`configs/model_affine_real.yaml`、`scripts/kaggle/jobs/gpu_stage4_b3.json`及 `gpu_affine_real_mm.json`为依据，固定seed0的 `train.seed=1234`、micro-batch=15、有效batch=30、50个epoch及已有学习率/验证选择协议。训练中仅有增益/相位增强，位置误差仍为测试项，不能临时加入某个模型。
4. **检查点选择。** 只按预定验证损失选择best checkpoint，不按测试SI-SDR挑epoch或从多次失败/重启中挑一次。G2续跑应保留optimizer、调度器、epoch与随机/采样状态，按同一总训练预算续完；不能把未完成预算的模型与完整模型差值称公平终局比较。实际完成epoch、best epoch、恢复日志、训练代码/配置/权重哈希都保留；若未达到计划预算，正式判读暂不成立，结果只作中期描述。
5. **共同输入。** 冻结数据配置、元数据、输入文件版本和ID清单；各模型同一语音、RIR、SIR/SNR、噪声和失配实现。模型形状不同会改变初始化随机数消耗，因此“同整数种子”不等于逐参数初始化相同；对比训练数据顺序/派生种子记录。首版仅是给定训练种子下的比较，不推论跨训练种子的稳定优势。
6. **算子资格。** 实系数乘复谱必须保留虚部；核验系数共轭、实际输出与有效滤波器重建的一致性。冻结下游评价定义；不得给F单独加oracle增益修正、单独改变DC处理、输出归一化、STFT或参考。若需要统一后处理，须在训练/评测前写v2并对所有模型一致实施。

资格项有缺失时保留该比较及失败原因，不能换一个更有利的对照填位。未满足同头/初始化匹配时，C1仍可描述该实现的差值，但不得使用“已排除输出层影响”的主张。

## 3. 指标、单位和逐样本配对

主指标为仓库逐样本字段 **`d_si_sdr_dp`（ΔSI-SDR，x_dp参考，dB，越大越好）**；同一ID输入相同，两个模型的Δ差等于输出SI-SDR差。沿用 [`src/metrics.py`](../src/metrics.py) 的定义及epsilon，不另加去均值/对齐。同步保留 `si_sdr_dp_out` 和输入指标。次指标固定为 `d_si_sdr`（x_ref）、`stoi_dp_out`、`pesq_dp_out`；不得看见排序后将主参考改为x_ref、将STOI改主指标，或将shadow SIR改名为BSS-eval。

按 `(数据集/几何, split, κ, 训练seed, method, id)` 唯一标识一行，再按ID配对。先检查两个T60组和输入指标一致；同一源内重复ID不允许静默覆盖。跨来源重复应先逐字段比对，选训练前确定的规范来源，保留被忽略源；不得拼接成额外样本。已有此类问题的处理依据见 [`duplicate_source_check.md`](streaming_cost_provenance/extension/duplicate_source_check.md)。

主评分要求全部预定ID都有有限输出。模型特异性的NaN、崩溃、空输出不得通过“只取有限交集”隐藏；报告失败ID/比例，该格主判读标为不可判定。若属输入本身缺陷，须在比较模型输出之前给所有模型冻结同一剔除列表、理由及修订记录。不得通过clip、输出增益调参或丢弃低分样本补齐。PESQ等次指标无法合法评分时如实记录缺失，不以其他指标补位。

### F的三个预定诊断：不能只看尺度不变的SI-SDR

记实际运行字典为H，波束输出 `z_p=h_pᴴy`，融合输出为 `Σ c_p z_p`，则实际有效滤波器 **`h=Σ conj(c_p)h_p`**。从混合输入计算一次c，冻结该c后分别作用于各成分；**不把神经网络重新喂入“只有目标”的输入来代替同一滤波器的目标失真。** 使用运行时字典/系数，以complex128计算诊断；保存逐句量，而不是把TF点当独立样本。

| 诊断 | 预先固定的定义 | 配对方向与实用门槛（非公认标准） |
| --- | --- | --- |
| 标称响应偏差 | `e_i(f,t)=|h_i(f,t)ᴴd_nom(f)−1|`；逐句 `D_i=P95(e_i)`，非DC、全时间点等权；同时报告逐句RMS、最大值和全局最大值。DC单列最大偏差，不丢弃DC导致的输出问题 | 对六格逐一看 `mean(D_F−D_A)`；≥0.01 为预定有意义的标称响应代价。另审查A的全局标称残余：>1e−3时先视为实现/精度资格问题，不借此认定结构不成立 |
| 目标单独通过的失真 | `TD_i=10log10(||x_dp||² / ||y_direct,frozen−x_dp||²)`，不做输出尺度优化；对应现有 `target_direct_sdr_out`。另列完整目标相对x_dp/x_ref的 `target_sdr_dp_out`/`target_sdr_out`，勿把晚期混响与直达分量混为一项 | 六格 `mean(TD_F−TD_A)≤−1 dB` 为预定目标失真代价；符号越负表示F更差 |
| 失配退化 | 同一ID下 `R_m(s,κ)=score_m(s,κ)−score_m(s,0)`；对κ=1/2分别取 `R_F−R_A`，两场景共四格 | 均值≤−0.5 dB为预定额外退化；仍必须并列所有绝对评分，不能把较高起点造成的更大下降直接说成较差的最终性能 |

`D`的1%门槛与−1/−0.5 dB门槛是本计划事前选定的工程解释尺度，不是IEEE标准或从新结果估出的阈值。标称残余的数值资格阈值也不是实测物理无失真证明。`D_i`分位数不保证每个TF点都满足约束，故保留最大值。

F的WNG必须用一般式 **`|hᴴd_nom|²/(hᴴh)`**；不得直接套用仅在仿射无失真条件下成立的 `1/(1/M+uᴴGu)`。WNG与SI-SDR都可能对整体尺度变化不敏感，所以WNG、系数和、目标增益幅相和目标失真共同报告。近零滤波器导致的未定义WNG记录为未定义/退化事件，不靠epsilon伪称满足WNG；标称响应仍按实际h计算。

## 4. 统计方案和固定检验族

对每个比较/格，先形成逐ID差 `d_i=metric_left−metric_right`。报告n、两模型均值、配对均值差、95%区间、中位差、原始p、Holm p、配对秩二列相关 `r_rb` 与 `Cohen dz=mean(d)/sd(d)`。主均值区间沿用现有审计的 `mean(d)±1.96*sd(d)/sqrt(n)`；它是给定数据/训练种子条件下的样本区间，不是训练随机性区间，也不是同时置信区间。

差异检验固定为双侧Wilcoxon符号秩、`zero_method=wilcox`、不作连续性校正；大样本固定渐近计算，记录SciPy版本，避免根据p值切换算法。使用浮点全精度差，不先四舍五入；绝对差并列用平均秩。全零差时p=1、r_rb=0，dz记未定义；不得把NaN当零效应。**Wilcoxon检验不是均值差检验**，其位置/对称性假设与均值CI的含义要分别说明。

为判定C1是否“实用上很小”，另预设六格的配对均值TOST等效性检验，等效界为 **[−0.5,+0.5] dB**：`p_eq=max(p(mean(d)>−0.5), p(mean(d)<+0.5))`，两单侧检验采用配对均值的Student-t、df=n−1。零方差时仅严格落在界内才可视为等效；不显著的Wilcoxon不能替代等效性检验。

| 族 | 固定假设数 | 内容及使用方式 |
| --- | ---: | --- |
| H8 | 36 | C1–C5 × 六格的30个主指标差异检验 + C1六格的6个TOST等效性p |
| HF | 16 | F−A的六个D偏差、六个目标TD差异、四个额外失配退化；均为双侧配对Wilcoxon，工程门槛另按上节判读 |
| HG2 | 4 | 两个G2仿真比较 × S1/S2、κ=0，主指标 |
| **H主（最终主张用）** | **56** | 合并H8+HF+HG2，统一Holm，α=0.05；可以附列各子族Holm，但**主判读只用56项全局校正，不选择更小p** |
| Href、Hstoi、Hpesq | 每族34 | 分别含8麦30比较及G2四比较；每个次指标各做Holm，α=0.05，只作预定次要结果，不能据此改写主终点 |
| HMIRD | 6 | M1–M3 × MIRD S1/S2的条件层主指标检验；Holm后作为有限条件的敏感性描述，解释限制见下一节 |

Holm按预定族的原始p从小到大，使用剩余检验数相乘并作累计最大值。缺失/资格失败的假设仍占预定槽位，校正计算可保守占位p=1，展示为“未执行/不可判定”而非实测p=1。不能删掉失败比较缩小检验族。次指标族与HMIRD不并入56项；明确只保证各自族内的错误率，不宣称所有指标共同的全局FWER。

预定稳健性附表：8麦对主均值差在两T60组内分别以ID为单位配对bootstrap，再按固定各半权重合并；20,000次，随机种子20261110，给percentile 95%区间。其角色是检查区间敏感性；不替换主CI，不以两者谁更有利为依据作主判读。T60、干扰数等异质性只完整描述，不新增挑选的p值。

## 5. MIRD六条件：估计层次和有限分辨率

条件由 `meta_mird_s1/s2.json` 的 `(rt60, subarray)` 定义：0.160/0.360/0.610 s × A/B，逐ID连接，每条件100条。先在每个条件内形成完整配对差，再取六个条件均值 `d_c`。总体描述为六条件等权平均（当前每组同样100条时等于600条的合并均值）；报告六条件全部均值/区间、方向、范围和主/次指标，不能只给合并分数。

条件层区间固定为 `mean(d_c)±t_(0.975,5)*sd(d_c)/sqrt(6)`。这是**这六个固定测量条件的描述性条件层区间**，不是跨独立房间/设备总体的保证；两子阵和T60条件也并非随机抽取的独立房间。条件层Wilcoxon使用对非零 `d_c` 的符号秩全枚举，两侧p由全部符号翻转计算，平均处理并列秩；零差剔除后保留有效条件数及假设。该敏感性计算仍依赖条件符号可交换等假设，不把它包装成真实世界总体检验。

**分辨率事前说明：**六个非零条件、双侧符号秩检验最小p为 `2/2^6=0.03125`；HMIRD有六个假设，Holm首步最小为 `6×0.03125=0.1875`。因此本版不可能凭这套条件层检验得到校正后p<0.05；不能在看到结果后换成600个“独立房间”来求显著。HMIRD用于完整披露，不设“显著才保留MIRD”的选择规则；这里的价值在效应、方向和局限。

另预定**条件内轨迹簇**敏感性区间：簇键为 `(rt60, subarray, 排序后的各干扰源trajectory_deg与dist)`；每条件内有放回重采样轨迹簇，簇内保留所有语音对，再计算条件均值及六条件等权平均，20,000次、种子20261110。只解释为给定测量响应的轨迹/语音采样变化。

当前元数据已确认MIRD S1每个条件仅一种轨迹，因此不能估计该条件内部的轨迹簇变异；不输出一个退化为零的bootstrap宽度冒充高精度，也不改回逐语音IID检验。MIRD S2有多种轨迹，可按上法计算；报告每条件簇数、聚类定义、CI与六条件描述是否冲突，不以更窄/更有利的区间替换另一种结果。

MIRD次指标仍列x_ref、STOI、PESQ和目标失真等完整条件描述，不凭未预定次指标p宣称获胜。不得把MIRD κ=0误说成“没有真实阵列失配”，也不得把实测RIR卷积语音误说成现场录制的噪声对话。

## 6. 看到结果前固定的文字判读规则

本节“显著”均指H主56项Holm p<0.05；同时展示主95%配对均值CI。工程门槛只针对观测均值，不把观测最小改善当总体下界。

| 结果模式 | 允许的解释 | 不允许的改写 |
| --- | --- | --- |
| C1六格的A−C观测均值均≥1 dB，均通过显著性，均值CI下界均>0，且同头资格通过 | “在该匹配实现、训练种子和指定六格中，解除凸约束仍伴随一致且较大的改善；观测均值至少1 dB。”与C2/C3/C4一同分解 | 不能说全部提升唯一由可行集合导致；CI下界未达1时不能声称总体收益至少1 dB；更不能说首次复融合 |
| C1六格均严格落在±0.5 dB内，且六个TOST均通过全局校正 | “同头后额外均值差在本计划实用界内；原有差距不能主要归为解除凸约束。”只有C4也出现一致、≥0.5 dB且显著的改善时，才补充“头设计/训练行为有贡献” | 非显著≠等效；仅均值<0.5但区间宽或TOST不通过时，只能说证据不够；C4未支持时不能改称头是主因 |
| C2六格R−C均≥0.5 dB且显著；或C3六格A−R满足同条件 | 分别支持允许负实权重、或复数自由度在该协议下有额外贡献；两条分别判断 | 不能由C2证明复相位有用；不能由C3证明只是解除非负性；最终输出维数/初始化未匹配时保留混杂 |
| 有格反向、仅部分格达到门槛，或差值处于0.5–1 dB/区间不确定 | 写清全部六格、方向与异质性，结论限定到满足规则的场景；全局概括为效应较弱/不一致或未定 | 不挑最好κ、T60、seed或参考代表整体，不换门槛，不把未定改成“趋势证明” |
| C1有格A显著更差，或C显著胜过A | 原样报告，并讨论本实现的优化/参数化和限制；撤回“一致更好”的表述 | 不删该格、不另选epoch、不同名字的模型或别的损失来救原结论 |

### F的主评分更高时如何判断无失真约束的价值

必须把C5全部六格与HF全部16项放在同一结果表。单格的预定不利证据需要同时满足：相应D/TD/退化的工程门槛、HF该检验通过H主全局校正、主95%均值CI排除零并与不利方向一致。

- 若F提高x_dp分数，但D代价成立，只能说“不约束带来主评分/标称幅相响应的交换”；SI-SDR对尺度不敏感，不能因此宣称目标无失真。结构约束的价值限定为保证/校准这个响应，而非保证所有指标最好。
- 若TD代价成立，说明在该格目标直达分量通过的保真有代价；若额外退化代价成立，说明该格相对κ=0更敏感。只有对应全部六格（D或TD）/全部四格（退化）一致成立，才用覆盖整个预定范围的措辞；否则逐格限定。绝对输出评分始终并列，退化更大不自动表示最终绝对分数更差。
- 若F六格主均值都至少高0.5 dB且显著，而没有达到上述不利证据门槛，写“本数据中自由融合的评分更高，未检出所预定的工程代价”；**不能写“无失真约束无价值”或“已证明无损/等效”**。本版没有为F设定工程安全性的非劣效检验，未检出损害不是安全性证明；应承认结构约束的评分成本及实证价值尚未得到支持。
- 若F未取得一致评分收益，则不能为了证明约束必要而只展示其失真更大的例子。负面结果仍保留；一个特定F实现的优化失败不证明所有无约束网络都不行。

### G2和MIRD的预定范围

G2只对上述G1/G2两个仿真比较按HG2/H主判读，保持mm与非mm区别。MIRD逐场景：六条件平均差>0、至少五个条件同向、且没有条件均值差≤−0.5 dB，才允许称“多数已测条件支持”；仍须同时给t区间、完整分组与HMIRD限制，不能称已证跨房间显著优势。任一条件不满足就写异质/未定，不删除MIRD。即使满足这个描述规则，STOI/PESQ或目标保真有冲突也要并列陈述，不升级为所有质量维度都改善。
